# 탄소 추적 시뮬레이터

세포호흡 · 발효 · 광합성에서 탄소 원자 하나하나를 ¹⁴C 표지처럼 색으로 따라가는 웹 시뮬레이터입니다.
설계는 [`docs/DESIGN.md`](docs/DESIGN.md)에 있습니다.

## 실행

`index.html` 파일 하나만 브라우저로 열면 됩니다. 설치, 빌드, 인터넷 연결이 필요 없습니다.

## 진행 상황

| 단계 | 내용 | 상태 |
|---|---|---|
| 1 | 설계안 | 완료 |
| 2 | 애니메이션 엔진 + 해당과정 + ¹⁴C 표지 선택 + 카운터 | 완료 |
| 3 | 피루브산 산화 + TCA 회로 (세포와 물질대사 수준으로 단순화) | 완료 |
| 4 | 산화적 인산화 + 억제제 + 그래프 | 간단 계산만 있음 (애니메이션 예정) |
| 5 | 발효 | 예정 |
| 6 | 광합성 | 예정 |
| 7 | 설명 패널 정리 | 예정 |

## 파일 안 구성

`index.html` 안의 `<script>` 블록이 설계안의 모듈에 대응합니다.

- `data/species` – 분자 구조식(탄소 좌표, 결합, 작용기)
- `data/reactions` – 반응과 탄소 매핑 (`'F16BP.C4': 'G3P.C1'` 형식)
- `data/layouts` – 장면 좌표와 효소 자리
- `data/explanations` – 설명 패널 문장
- `model` – 매핑 검사와 반응 실행
- `anim` – 분자 흐름, 반응 애니메이션, 그리기
- `ui` – 조작, 카운터, 누적표, 자가 검사

페이지 아래 "자가 검사" 칸에서 탄소 매핑과 화학량론 검사 결과를 볼 수 있습니다.
