# 탄소 추적 실험실

세포호흡과 광합성의 전 과정을 버튼으로 한 단계씩 직접 진행해 보는 웹 시뮬레이터입니다.
방사성 동위원소(¹⁴C) 추적법처럼 **탄소 원자 하나하나에 서로 다른 색과 번호**를 붙여서, 각 탄소가 어떤 물질을 거쳐 어디로 가는지 따라갈 수 있습니다.

## 실행

설치나 빌드 없이 `index.html`을 브라우저로 열면 됩니다. GitHub Pages로 배포해도 그대로 동작합니다.

## 세포호흡 탭

| 단계 | 장소 | 탄소의 이동 |
|---|---|---|
| ① 포도당 활성화 | 세포질 | 포도당 → 과당 1,6-이인산 (ATP −2) |
| ② 6탄소 분해 | 세포질 | C1~C3은 DHAP를 거쳐 순서가 뒤집힌 G3P, C4~C6은 바로 G3P |
| ③ 에너지 회수 | 세포질 | G3P → 피루브산 (ATP +4, NADH +2) |
| ④ 피루브산 산화 | 미토콘드리아 | 피루브산의 카복실기 탄소(포도당 C3·C4)가 CO₂로 방출 |
| ⑤ TCA 회로 (8반응) | 미토콘드리아 기질 | 첫 바퀴의 CO₂ 2개는 **원래 있던 옥살아세트산**의 탄소. 석신산의 대칭성 때문에 탄소 배치가 50% 확률로 뒤집힘 |
| ⑥ 전자 전달계 | 내막 | NADH ×2.5, FADH₂ ×1.5 ATP, O₂ → H₂O |

- 산소를 끄면 미토콘드리아가 멈추고 알코올 발효(CO₂ 방출) 또는 젖산 발효를 선택할 수 있습니다.
- 옥살아세트산이 계속 재사용되므로 포도당을 여러 개 넣으면 앞선 포도당의 탄소가 나중 바퀴에서 빠져나가는 것을 볼 수 있습니다.

## 광합성 탭

| 단계 | 장소 | 내용 |
|---|---|---|
| CO₂ 공급 | 대기 | 들어오는 CO₂마다 새 색 표지 |
| ① 명반응 | 틸라코이드 | H₂O 분해 → O₂, ATP, NADPH (빛 세기 조절 가능) |
| ② 탄소 고정 | 스트로마 | CO₂ + RuBP → 3-PGA 2분자, 표지 탄소는 3-PGA의 C1(카복실기) |
| ③ 환원 | 스트로마 | 3-PGA → G3P (ATP, NADPH 소비) |
| ④ G3P 내보내기 | 세포질로 | 내보낼 G3P를 직접 골라 볼 수 있음 |
| ⑤ RuBP 재생 | 스트로마 | 5 G3P → 과당 6-인산, 에리트로스 4-인산, 세도헵툴로스 7-인산, 5탄당을 거쳐 3 RuBP (실제 탄소 재배치 반영) |
| ⑥ 포도당 합성 | 세포질 | G3P 2분자 → 포도당 |

- 빛을 끄면 3-PGA는 쌓이고 RuBP는 줄어드는 고전적 실험 결과를 재현할 수 있습니다.
- 만든 포도당을 **세포호흡 탭으로 보내** 광합성에서 고정된 탄소가 호흡에서 다시 CO₂로 나가는 과정을 이어서 볼 수 있습니다 (번호 앞에 `P` 표시).

## 이동 애니메이션

반응 하나하나가 순서대로 진행됩니다. 반응물 속 탄소가 반짝인 뒤 반응 장소(예: 루비스코)로 모이고, 그 자리에서 생성물 모양으로 다시 늘어선 다음 각 생성물의 자리로 이동합니다. 지나간 길은 그 탄소의 색으로 선이 그려졌다가 사라집니다. 상단의 속도 막대로 빠르기를 조절할 수 있습니다.

## 탄소 색 규칙

- 새로 들어온 탄소(포도당, CO₂)는 모두 **서로 다른 색 + 번호**를 가집니다.
- 처음부터 세포 안에 있던 탄소(옥살아세트산, RuBP)는 회색입니다. 상단의 "원래 있던 탄소도 색으로 구별"을 켜면 이들도 옅은 색으로 구분됩니다.
- 탄소에 마우스를 올리거나 누르면 출처와 지나온 경로가 나오고, 추적표의 행을 누르면 해당 탄소가 깜빡입니다.

## 파일 구성

- `index.html` – 화면 구조
- `css/style.css` – 스타일 (라이트/다크 모드)
- `js/app.js` – 시뮬레이션 엔진과 두 시뮬레이터
- `tools/build-single.py` – 모든 파일을 한 HTML로 합치는 스크립트
