# 세포호흡 · 발효 · 광합성 실험실 설계안

세포호흡 · 발효 · 광합성을 하나의 시뮬레이터로 만들고, 탄소 원자 하나하나를 ¹⁴C 표지처럼 색으로 추적한다.
이 문서는 1단계(설계) 결과물이다. 코드는 확인을 받은 뒤 2단계부터 작성한다.

---

## 수정 사항 (사용자 요청)

- **파일 형식**: Vite 프로젝트 대신 `index.html` 한 파일. 설계의 모듈 구분은 파일 안 `<script>` 블록으로 나눴다.
- **내용 수준**: 2022 개정 교육과정 「세포와 물질대사」 수준으로 단계를 줄였다.
  - 해당과정: 포도당 → 과당 2인산 → 피루브산 2분자 (2단계)
  - 피루브산 산화: 피루브산 → 아세틸 CoA + CO₂
  - TCA 회로: 시트르산 → 5탄소 화합물 → 4탄소 → 4탄소 → 4탄소 → 옥살아세트산
  - 분자는 탄소 골격(원 + 번호)만 그리고, 실제 물질 이름(α-케토글루타르산, 석신산 등)은 툴팁과 "더 알아보기"에만 넣는다.
  - 단계를 묶었어도 탄소 매핑은 실제 효소 반응을 이어 붙인 결과라서 정확도는 그대로다(석신산 대칭 섞임 포함).
- 전자 전달계, 발효, 광합성까지 모두 같은 파일에 들어 있다. 탭(세포호흡 · 발효 · 광합성)마다 따로 돌아가는 세계(상태)를 둔다.
- 전자 전달계와 명반응의 속도는 상대값 모델이다(기울기 역압으로 호흡 조절, 억제제는 해당 단계의 속도를 농도만큼 줄임).
- 아래 0~7절의 Vite 파일 구조와 세부 반응 목록은 처음 설계안으로 남겨 둔다.

### 2-4. 보조인자 장부 (`model/ledger.js`)

숫자를 두 가지로 나눠 보여준다.

- **현재 풀**: ATP/ADP, NADH/NAD⁺, FADH₂/FAD, NADPH/NADP⁺의 현재 개수. 합계는 일정하게 유지된다. 그래서 NAD⁺가 바닥나면 해당과정과 TCA가 실제로 느려진다.
- **누적**: 단계별로 생성하거나 소모한 양. 포도당 1분자 기준 표는 이 값을 처리한 포도당 수로 나눠 만든다.
- ATP가 계속 쌓이기만 하면 ADP가 없어 합성효소가 멈춘다. 그래서 "세포의 ATP 사용량" 설정을 둔다(기본값은 중간). 이 값을 0으로 하면 호흡 조절(ADP가 부족해 호흡이 느려지는 현상)도 관찰할 수 있다.
- ATP 환산 기준 토글
  - 2.5 / 1.5 (현재 교과서): 해당과정 NADH 셔틀에 따라 30 또는 32
  - 3 / 2 (옛 교과서): 36 또는 38

## 3. 시뮬레이션 엔진

### 3-1. 두 층 구조

```
[모델 층]  scheduler ──► reactionEngine ──► 이벤트 {반응, 반응물, 생성물, 원자 매핑, 보조인자 변화}
                │                                   │
        bioenergetics (매 프레임 미분방정식)           ▼
[화면 층]                               transitions ──► 원자 이동 · 결합 페이드 · 입자
                                                    │
                                    "commit 순간" ──► ledger 갱신 → 카운터 반짝임
```

- **모델 층**은 화면 없이도 돌아간다. 테스트는 이 층만 실행해서 수천 번 반복한다.
- **화면 층**은 이벤트를 받아 연속 애니메이션으로 바꾼다. 장부 숫자는 원자가 반응 자리에서 생성물로 재배열되는 순간(commit)에 바뀐다. 그래서 숫자와 원자 움직임이 맞는다.

### 3-2. 분자의 흐름 (공간 에이전트)

- 각 분자는 자기를 쓸 다음 반응의 효소 자리를 목표로 삼는다. 그쪽으로 떠다니듯 이동한다(약한 무작위 운동 + 목표 방향 흐름).
- 효소 자리에 반응물이 다 모이고 보조인자가 있으면 반응이 일어난다. 효소마다 처리 시간이 있어서, 계속 공급하면 효소 앞에 줄이 생긴다. 이것으로 대사 흐름과 병목이 보인다.
- 구획 이동은 실제 경로를 따른다. 피루브산은 미토콘드리아 외막과 내막을 통과하고, CO₂는 세포막 밖으로 나가며, 광합성의 CO₂는 기공에서 엽록체 안으로 들어온다.
- 화면에 동시에 있는 분자 수에는 상한을 둔다. 공급량이 상한을 넘으면 입구에서 기다린다.

### 3-3. 재생 방식

| 방식 | 동작 |
|---|---|
| 재생 | 시간이 흐르며 반응 속도에 따라 반응이 계속 일어난다. 속도 0.25×~4× |
| 일시정지 | 화면과 모델이 모두 멈춘다. 멈춘 상태에서도 원자 툴팁은 볼 수 있다. |
| 한 단계 | 다음 반응 하나가 애니메이션까지 끝나면 멈춘다. |
| 반복 | 포도당이나 CO₂를 정해진 간격으로 계속 공급한다. |

### 3-4. 전자전달 · H⁺ 기울기 모델 (`model/bioenergetics.js`)

실제 단위가 아니라 **경향을 맞추는 상대값 모델**이다. 그래프 축에도 "상대값"이라고 쓴다.

미토콘드리아 상태 변수: NADH, Q 환원 비율, 사이토크롬 c 환원 비율, Δp(H⁺ 기울기), O₂, ATP/ADP

| 흐름 | 속도식(개념) |
|---|---|
| 복합체 I | k₁ · NADH · Q산화형 · 역압(Δp) · (1 − 로테논) |
| 복합체 II | k₂ · FADH₂ · Q산화형 · 역압(Δp) |
| 복합체 III | k₃ · QH₂ · c산화형 · 역압(Δp) · (1 − 안티마이신) |
| 복합체 IV | k₄ · c환원형 · O₂/(K+O₂) · 역압(Δp) · (1 − 사이안화물) |
| ATP 합성효소 | kₛ · ADP · 구동력(Δp) · (1 − 올리고마이신) |
| 누출 | (k누출 + 짝풀림제) · Δp → 열 |

- 역압(Δp)은 Δp가 클수록 작아진다. 이것으로 올리고마이신을 넣으면 기울기가 커지고 전자전달과 O₂ 소비가 줄어드는 현상이 나온다.
- H⁺ 펌핑 수: 복합체 I 4개, III 4개, IV 2개(NADH 1개 → 10 H⁺, FADH₂ 1개 → 6 H⁺). ATP 1개에 약 4 H⁺(운반 포함).
- 막사이 공간의 H⁺ 입자 수는 Δp에 비례해서 그린다. e⁻와 H⁺ 입자는 각 흐름 속도에 맞춰 생성한다.

엽록체도 같은 틀을 쓴다: 광계 II(빛 × 흡수율(파장)) → PQ → b₆f → PC → 광계 I → Fd → NADP⁺ 환원, 틸라코이드 내부 H⁺, ATP 합성효소. 순환적 전자흐름을 켜면 Fd → PQ 경로가 열린다.

### 3-5. 억제제 (`model/inhibitors.js`)

| 억제제 | 작용 지점 | 이 모델에서 나타나야 할 결과 |
|---|---|---|
| 로테논 | 복합체 I | NADH가 쌓이고 NAD⁺가 줄어 TCA가 느려진다. FADH₂ 경로(복합체 II)는 남아서 O₂ 소비가 **완전히 0이 되지는 않는다**. |
| 안티마이신 A | 복합체 III | QH₂가 쌓이고 O₂ 소비와 펌핑이 멈추며 Δp가 무너진다. |
| 사이안화물 | 복합체 IV | 사이토크롬 c까지 환원 상태로 쌓이고 O₂ 소비가 0이 된다. |
| 올리고마이신 | ATP 합성효소 | Δp가 과도하게 커지고 전자전달과 O₂ 소비가 줄어든다. |
| DNP / FCCP | 막 누출 | Δp가 무너지고 ATP 합성은 줄지만 O₂ 소비는 늘어난다. 열 입자가 생긴다. |

각 억제제에는 켜기/끄기와 농도 슬라이더(0~100%)가 있다. 켜거나 끄는 순간 그래프에 세로선과 이름표를 남긴다.

## 4. 애니메이션 엔진

### 4-1. 반응 장면 하나 (transitions.js)

1. **집중**: 반응물 분자가 효소 자리에 도착하면 반응할 탄소가 반짝인다.
2. **결합 분리**: 반응물에만 있는 결합선은 서서히 사라진다. 결합은 "원자 id 쌍"으로 비교해서 반응물에만 있는 결합, 생성물에만 있는 결합, 양쪽에 있는 결합을 자동으로 구분한다.
3. **이동**: 각 탄소가 지금 위치에서 생성물 구조식 속 자기 자리로 3차 베지어 곡선을 따라 easing으로 움직인다. 지나간 길은 그 탄소 색으로 남았다가 사라진다.
4. **결합 형성**: 생성물에만 있는 결합선이 서서히 나타난다. 이 순간이 commit이고, 장부 숫자가 바뀐다.
5. **떠나기**: 생성물이 다음 효소 자리로 흘러간다. CO₂는 세포 밖으로 날아간다.

원자는 장면이 바뀌어도 사라지거나 순간 이동하지 않는다. 모든 위치 변화는 tween을 거친다.

### 4-2. 그리기 순서 (매 프레임)

배경(미리 그려 둔 세포 구조) → 막 단백질과 효소 자리 → H⁺·e⁻ 입자 → 결합선 → 탄소 원(색 + 번호) → 궤적 → 이름표 · 툴팁

- 기준 좌표계는 1600 × 900이다. 화면 크기에 맞춰 축척하고 기기 해상도(DPR)를 반영한다. 태블릿 세로 화면에서는 장면 아래에 패널이 오도록 배치를 바꾼다.
- 움직임 줄이기 설정을 켠 사용자에게는 이동 시간을 줄이고 궤적을 정지 화살표로 대신 보여준다.

### 4-3. 색과 표지

- 포도당 C1~C6: Okabe–Ito 색맹 안전 팔레트 6색을 쓴다. 색만으로 구별하지 않도록 원 안에 번호도 넣는다.
- **¹⁴C 표지 위치 선택**: 체크박스로 C1~C6를 고르고, 고르지 않은 탄소는 회색으로 보인다. 원자 자체는 그대로 두고 그릴 때만 거른다. 그래서 진행 중에 체크를 바꿔도 지금까지의 경로가 바로 다시 칠해진다.
- **광합성 펄스-체이스**: CO₂ 투입 회차마다 다른 색과 회차 번호를 준다. "체이스" 버튼을 누르면 이후 CO₂는 표지 없이(¹²C, 회색) 들어온다.
- 원래 세포 안에 있던 탄소(옥살아세트산 풀, RuBP 풀)는 회색으로 시작한다. 선택하면 옅은 색으로 구분해서 볼 수 있다.

```
┌ 탭: 세포호흡 | 발효 | 광합성 ──────────── 재생 ⏸ ⏭ ⟲  속도 ─────┐

│ │ O₂ 농도   │ │                                     │ │ NADH ... │ │
│ │ 억제제    │ │                                     │ │ CO₂ O₂   │ │
│ │ 표지 선택 │ │                                     │ └─────────┘ │
│ └──────────┘ └─────────────────────────────────────┘             │
│ ┌ 실시간 그래프 ───────────────┐ ┌ 단계별 누적표 ──────────────┐ │
│ └──────────────────────────────┘ └──────────────────────────────┘ │
│ ┌ 설명 패널 (현재 단계 강조 · 더 알아보기 · 비교표) ───────────┐ │

```

| 탭 | 장면 | 그래프 |
|---|---|---|
| 세포호흡 | 세포질(해당과정) + 미토콘드리아 단면(외막 · 막사이 공간 · 내막 위 복합체 I~IV와 ATP 합성효소 · 기질의 TCA 효소 8자리) | O₂ 소비, ATP 생성 속도, H⁺ 기울기, NADH/NAD⁺ |
| 발효 | 세포질 확대 + NAD⁺ ⇄ NADH 순환 고리 강조 | ATP 생성(호흡과 비교), NADH/NAD⁺ |
| 광합성 | 기공 → 엽록체(틸라코이드 막 위 광계 II · PQ · b₆f · PC · 광계 I · FNR · ATP 합성효소, 스트로마의 캘빈 효소 자리) | RuBP, 3-PGA, ATP, NADPH, O₂ 발생 |

- 세포호흡 탭에서 O₂를 0으로 내리면 NADH가 쌓이고, 피루브산이 발효 경로로 넘어간다. 발효 탭은 같은 엔진에 산소 0과 세포질 확대 화면을 미리 설정한 것이다.
- 광합성 조작: 빛 세기, 파장(400~700 nm, 엽록소 흡수 스펙트럼으로 효율 결정), CO₂ 농도, 순환적 전자흐름, 펄스/체이스

## 6. 검증 계획 (각 단계에서 자동 테스트)

### 6-1. 구현 전에 확인한 기댓값

아래 값은 반응 매핑을 그대로 몬테카를로로 20만 번 돌려서 확인했고, 교과서 값과 일치한다.

| 표지 위치 | 결과 |
|---|---|
| 포도당 C3, C4 | 피루브산 C1(카복실기) → 피루브산 산화 때 100% CO₂ |
| 포도당 C2, C5 | 피루브산 C2 → 아세틸 CoA 카보닐 탄소 → TCA **1회전 0%, 2회전 100%** CO₂ |
| 포도당 C1, C6 | 피루브산 C3 → 아세틸 CoA 메틸 탄소 → **1·2회전 0%, 3회전 50%, 4회전 25%, 5회전 12.5% …** |
| TCA 1회전에서 나가는 CO₂ | 옥살아세트산의 C1(아이소시트르산 탈수소효소), C4(α-케토글루타르산 탈수소효소) |
| 알코올 발효 CO₂ | 피루브산 C1 = 포도당 C3, C4 |
| 젖산 발효 | 탄소 3개 모두 젖산으로 (CO₂ 0) |
| 루비스코 직후 | 새 탄소 → 3-PGA C1(카복실기) |
| 첫 헥소스 | 표지가 C3, C4에 나타남 (G3P C1 두 개가 만나는 자리) |
| RuBP 재생 후 | G3P C1 표지가 RuBP C1 : C2 : C3 = 1 : 1 : 3 으로 퍼짐 (C3가 가장 진함) |

"회전"은 그 아세틸 CoA가 들어간 회전을 1회전으로 센다. 원자마다 `acetylTurn`을 기록해서 화면의 추적표에도 "3회전째에 CO₂로 방출"처럼 보여준다.

### 6-2. 화학량론 테스트

- 포도당 1분자 해당과정: ATP −2 +4, NADH +2, 피루브산 2
- 피루브산 산화: NADH 2, CO₂ 2
- TCA(2회전): NADH 6, FADH₂ 2, ATP(GTP) 2, CO₂ 4
- 산화적 인산화: 기준별 합계 30/32 또는 36/38
- 캘빈 회로 CO₂ 3개: ATP 9, NADPH 6 소모, G3P 1 순생산
- 모든 반응에서 탄소 원자 수 보존(원자 객체가 사라지거나 복제되지 않음)

### 6-3. 불확실하거나 단순화한 부분 (화면의 "더 알아보기"에도 표시)

- **P/O 비(2.5, 1.5)와 H⁺/ATP 비**는 측정값을 바탕으로 한 근사다. 해당과정 NADH의 셔틀(말산-아스파르트산 / 글리세롤인산)에 따라 30과 32가 갈린다.
- **엽록체 ATP 수지**: 비순환 전자흐름만으로는 O₂ 1분자당 ATP 약 2.6, NADPH 2가 생긴다(ATP 합성효소 c-고리 14개 기준). 캘빈 회로가 요구하는 ATP:NADPH = 3:2에 조금 모자란다. 부족분은 순환적 전자흐름이 채운다는 설명을 넣는다. c-고리 수는 생물마다 다르다.
- **속도 상수**는 실제 효소 속도가 아니라 현상(억제제 반응, 빛 끄기 실험)이 교과서대로 나오도록 정한 값이다.
- **파장별 효율**은 엽록소 a·b 흡수 스펙트럼을 가우스 곡선 합으로 근사한다. 적색 저하(680 nm 이상)는 간단히 반영하고, 에머슨 증강 효과는 "더 알아보기"에서 글로만 다룬다.
- **포도당 합성**: 실제로 캘빈 회로 산물은 세포질에서 설탕, 스트로마에서 녹말로 간다. 시뮬레이터는 "포도당(헥소스)" 하나로 단순화한다.
- **옥살아세트산 풀**: 실제 세포에서는 여러 분자가 섞인다. 시뮬레이터는 분자를 하나하나 추적하므로 회전 수를 원자 단위로 셀 수 있다.
